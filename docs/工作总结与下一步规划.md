## 四、架构红线（必须继续遵守）

1. **同一个学习事实，只允许一个模块拥有写权限**（现在是 LearningEvent）
2. **CandidateAssessment 不被计算两次**（UI/SRS/LearningEvent 消费同一结果）
3. **UI 不掌握学习逻辑**（学习逻辑在 service 层）
4. **HumanSL 不临时改变页面排序**（终算后缓存，到处读取）
5. **功能必须帮助 发现/理解/训练/减少 问题，否则不做**
