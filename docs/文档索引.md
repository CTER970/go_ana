# 文档索引

本文档用于把当前项目里已经存在的说明材料重新分层，避免每次都从长篇历史记录里找入口。

## 先看哪一份

1. 只想使用分析器：先看根目录 [README.md](../README.md)，再看 [快速开始.txt](../快速开始.txt)。
2. 想掌握分析器功能：看 [analyzer/README.md](../analyzer/README.md)。
3. 想了解项目全貌：看 [项目说明.md](../项目说明.md)。
4. 想继续开发：看 [KataGo/当前任务.md](../KataGo/当前任务.md) 和 [KataGo/当前任务实现思路](../KataGo/当前任务实现思路)。
5. 只想运行 KataGo 引擎：看 [katago-runtime/README-RUN.txt](../katago-runtime/README-RUN.txt)。

## 当前项目状态摘要

- 分析器当前版本：v4.32。
- 功能主线：个人复盘、AI 推荐、整盘分析、问题手、阶段训练、错题本、个人画像和棋风成长路线。
- UI 主线：棋盘为视觉主体，右侧为研究工作台，顶部只保留少量全局入口。
- 已知验证边界：v4.31 真实 Tk 综合冒烟完整通过；v4.32 已通过非 UI、静态、结构和产品逻辑测试，真实 Tk 复跑曾因运行额度限制待补。

## 开发者常用命令

```powershell
cd D:\katago\analyzer
python -m py_compile app.py ui_product.py
python test_ui_product.py
python test_ui_design.py
```

需要真实界面冒烟时：

```powershell
cd D:\katago\analyzer
python test_ui_smoke.py
```

需要直接验证 KataGo 引擎时：

```powershell
cd D:\katago\katago-runtime
.\katago-eigenavx2.exe gtp
```
