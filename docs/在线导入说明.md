# 在线导入说明（URL 下载 + OGS 对局批量导入）

> 功能入口：主界面右侧「棋谱」卡片 →【在线导入（URL / OGS）】按钮。
> 实现模块：[analyzer/online_import.py](../analyzer/online_import.py) · 测试：[analyzer/test_online_import.py](../analyzer/test_online_import.py)

## 这个功能做什么

在不上传任何数据的前提下，把互联网上**公开可下载**的棋谱直接拉进本地棋谱库：

- **① 从链接导入**：粘贴一个 `.sgf` 直链或 OGS 对局页链接 → 后台下载 → 自动入库并排队 KataGo 分析。
- **② 从 OGS 导入**：输入 [OGS](https://online-go.com)（Online-Go Server，全球最大开源围棋服务器）用户名 → 查询最近 30 盘已结束对局 → 勾选任意多盘 → 批量下载入库。

下载在后台线程执行，界面不卡；入库走棋谱库统一管道（按 SGF 内容 SHA1 去重、不覆盖已有分析缓存），之后自动进入后台分析队列，与本地批量导入的行为完全一致。

## 支持的链接格式

| 输入 | 例子 | 处理方式 |
|---|---|---|
| OGS 对局页 | `https://online-go.com/game/89887270` | 自动转换为官方 API 的 SGF 地址下载 |
| OGS API 直链 | `https://online-go.com/api/v1/games/89887270/sgf` | 直接下载 |
| 任意 `.sgf` 直链 | `https://example.com/kifu/2024-final.sgf` | 直接下载 |
| 其他页面 | `https://www.19x19.com/...` | 明确拒绝并提示改用导出/粘贴方式 |

## 星阵 / 涨棋网 / 野狐等平台怎么办

这些平台**没有公开的棋谱接口**（已调研确认），自动抓取需要模拟登录、违反其用户协议且有封号风险，因此本工具不做自动抓取。半自动路径已经足够顺：

1. 在平台官网/App 的棋谱库中打开对局，用官方「导出/分享」功能拿到 SGF 文件或文本。
2. 三选一入库：
   - 【粘贴 SGF】按钮：直接粘贴文本；
   - 把 `.sgf` 文件丢进收件箱文件夹（棋谱库窗口 →【打开收件箱】），【扫描收件箱】即可；
   - 如果平台给出的是 `.sgf` 下载直链，用本功能的①区粘贴链接即可。

## 合规与安全设计

- **只读公开数据**：仅 GET 请求公开棋谱，不上传、不登录、不带任何账号信息。
- **限速**：相邻请求间隔 ≥0.6 秒，单线程顺序下载，不做并发抓取；OGS 单次查询最多 30 盘。
- **超时与上限**：单请求 20 秒超时，响应超过 8MB 直接中止。
- **纯标准库**：网络层只用 `urllib`，不新增 pip 依赖，项目仍可裸 `python app.py` 启动；不点在线导入时程序行为与之前完全一致（离线可用不受影响）。
- **友好报错**：404、断网、超时、非 SGF 内容都翻译成可直接看懂的中文提示，单盘失败不阻断批量任务。

## 技术架构

```
【在线导入】对话框 (app.py open_online_import)
   │  worker 线程（网络 IO）            UI 线程（库写入）
   ├─ download_from_url(url)      ──┐
   ├─ ogs_list_games(username)       ├─ events 队列 + after 轮询
   └─ download_ogs_games(games)   ──┘
                                     └─ import_sgf_text(text, source_kind=...)
                                          └─ SHA1 去重 → game_library 索引 → 分析队列
```

关键决策：

- **下载与入库分线程**：`game_library` 的 `index.json` 是读-改-写模式，全部写操作收敛在 UI 线程，worker 只做网络 IO，避免并发写竞争。
- **网络单出口**：所有请求经过 `online_import._http_get()`（限速/超时/大小上限/错误翻译集中在一处），测试用 monkeypatch 替换它即可全离线跑通。
- **适配器易扩展**：OGS 逻辑集中在 `ogs_find_player / ogs_list_games / ogs_game_sgf` 三个函数；未来若某平台开放接口，照此结构加一组函数即可接入，UI 不用改。
