# 阶段训练升级方案（胜率崩盘段 · 重下对弈 · 走势评价）

> 版本：v1（方案，未实施） ｜ 依据：用户需求"从胜率降低最多的一段作为训练，约 40 手，和 AI 重下，判断胜率走势与发挥情况" ｜ 现状基线：`training.py` / `training_analysis.py` / app 阶段训练 UI

---

## 一、现状与差距（诚实盘点）

现有阶段训练已经具备：

| 能力 | 现状 | 与需求的差距 |
|---|---|---|
| 选段 | 36 手窗口、12 步滑动，按**混合分**选最差段（目损总和 + 胜率损失×0.35 + 恶手计数 + 连续问题 streak） | 不是"胜率降低最多的一段"：混合分会被多个小目损淹没一次大崩盘；窗口固定 36 手 |
| 重下 | 从段起点和 KataGo 对下，AI 应手，隐藏候选，最多 ~40 手 | ✅ 基本符合（支持到 40 手） |
| 评价 | 平均目损 vs 实战平均 → A/B/C/D + 问题手 + 建议；`training_analysis` 已算 `winrate_drop_improvement` | **没有胜率走势对比**：用户看不到"我的曲线 vs 实战曲线"这条最直观的证据；胜率维度只在汇总数字里 |
| 复练 | 训练记录入库（trainingSessions），可"重来" | 没有跨轮次趋势（这一段第 1/2/3 轮的进步轨迹） |

结论：**重下引擎不用动**，改造集中在三处——选段准则、走势可视化、走势维度的评价。

---

## 二、改造设计（三块）

### A. 选段升级：真正的"胜率崩盘段"

**A1. 新增选段模式 `winrate_crash`（与现有混合分模式并存，默认切换为新模式）**

```
段得分 = 玩家视角累计胜率跌幅（段内每手 player_wr_loss 之和，百分点）
```

- 只看胜率：一段"从 62% 跌到 31%"的崩盘段即使目损分散也必然得分最高；
- 混合分模式保留为"问题密集段"选项（设置里可切），两种模式理由文案不同。

**A2. 崩盘段自动定界（不硬切 36 手）**

以最大跌幅窗口为种子，向两端扩张直到满足停机条件：

- 向前扩：上一手的玩家视角胜率损失 < 1.5 个百分点（进入平静期）或触及对局起点；
- 向后扩：同理，或胜率已稳定（连续 4 手波动 < 2pp）；
- 长度钳制在 **[20, 48] 手**（用户预期约 40 手；低于 20 手的"一刀致命"更适合单点主动复盘，不该进阶段训练）。

**A3. 选段理由文案（训练开始前展示，可核对）**

```
本段训练：第 63–104 手（42 手）
实战胜率：62.4% → 31.0%（-31.4 个百分点）
主要损失：第 71 手 -8.2pp ｜ 第 89 手 -6.7pp ｜ 第 97 手 -5.9pp
```

数据全部来自已存分析，不重算。

### B. 训练中：双走势实时对比

**B1. 训练态下复用胜率曲线窗口，画两条线**：

- 灰色实线 = 原实战玩家视角胜率（段内）；
- 青色实线 = 我当前重下的胜率（每落一子随分析回流延长）；
- 两线之间的面积直观显示"挽回 / 再丢"。

**B2. 训练 banner 增加 Live 指标**（每回合分析回流后刷新）：

```
重下胜率 48.2%（实战同期 41.5% ▲+6.7pp）｜ 本轮目损均值 0.42
```

**B3. 结束条件不变**（段末/停一手/手动结束），另加"提前达标"提示：当重下曲线已稳定高于实战曲线 8pp 且连续 8 手无恶手时，提示"本段已明显改善，可提前结束"（不强制）。

### C. 训练后：走势维度的评价

**C1. 结算页新增"走势对比卡"**（置于 A/B/C/D 之上，先看图再看分）：

- 双曲线全段对比图（同 B1 数据的最终版）；
- 三个走势指标：
  - **胜率恢复量** = 段末(重下) − 段末(实战)，百分点；
  - **最大回撤差** = max(实战段内最大回撤 − 重下段内最大回撤, 0)——"这次没崩那么深"；
  - **挽回面积占比** = 两曲线间面积 / 实战跌幅总面积。

**C2. 评分融合（不动 A–D 框架，改判据权重）**：

```
综合分 = 0.5 × 目损改善度（现有 improvement 归一化）
      + 0.3 × 胜率恢复量归一化（恢复 ≥ 段跌幅 60% 记满分）
      + 0.2 × 恶手控制（段内 0 恶手记满分）
```

A/B/C/D 阈值不变，但**评语首句改成走势语言**（用户的心智模型）：

```
A：胜率曲线整段压住实战，段末高出 12.3pp——这一段你已能独立掌舵。
C：前半段挽回了 9pp，但第 89 手附近再次快速回落，问题模式仍在。
```

**C3. 跨轮次趋势**：同一段（同 game_id + 段哈希）历史训练列出小趋势条 `第3轮 ▲ 段末胜率 38→47→53%`，数据来自已存 trainingSessions，只需聚合。

## 三、与学习系统的联动（不新增事实源）

- 训练结束照旧走 `apply_training_outcome(source="training")`：good 封顶 understanding，不冒充 retained——本方案不改变掌握语义；
- 走势三指标（恢复量/回撤差/挽回占比）作为 `TrainingAnalysis` 新字段随会话入库，供"我的学习"页日后消费；
- 训练段选择理由（A3 文案）同时写入任务 dict，错题/学习事件不重复存储。

## 四、UI 改动清单（全部复用现有容器）

| 位置 | 改动 |
|---|---|
| 训练开始横幅 | 选段理由三行（A3）+ "换一段（问题密集段）"切换按钮 |
| 训练 banner | Live 双指标行（B2）+ 提前达标提示（B3） |
| 胜率曲线窗口 | 训练态双曲线模式（B1）；非训练态不变 |
| 训练结算 | 走势对比卡（C1）+ 新评语（C2）+ 轮次趋势行（C3） |
| 设置 | 选段模式：胜率崩盘段（默认）/ 问题密集段；段长 20–48 钳制说明 |

## 五、测试计划

1. 选段：构造"多小亏段 vs 单段大崩盘"，断言新模式选中大崩盘段、混合分可切回；
2. 定界：崩盘后平静 4 手 → 段在平静前截止；两端钳制 [20,48]；
3. 走势指标：固定两曲线序列，断言恢复量/回撤差/挽回占比数值；
4. 评分融合：同目损不同走势 → 等级可分（恢复多者不降级）；
5. 回归：现有 `test_training*.py` 全绿（混合分模式与旧评分作为兼容路径保留断言）。

## 六、实施顺序与规模

| 步骤 | 内容 | 规模 |
|---|---|---|
| 1 | A1+A2+A3 选段升级（纯逻辑 + 测试） | 小 |
| 2 | C1+C2 走势指标与结算卡（纯逻辑 + 曲线窗口训练态） | 中 |
| 3 | B1+B2 训练中实时双曲线 | 中 |
| 4 | C3 轮次趋势 + 设置项 | 小 |

步骤 1、2 无 UI 风险可先行；步骤 3 涉及曲线窗口状态机，放最后。
