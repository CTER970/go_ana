# 基于个人历史实战的围棋学习系统

> 文档导航：如果是第一次打开项目，请先看根目录 [README.md](../README.md)；如果想了解所有说明文档的分工，请看 [docs/文档索引.md](../docs/文档索引.md)。本文主要说明 `analyzer/` 学习系统本身。

一个“棋局状态管理 + KataGo 分析”的最小闭环原型：打开窗口（**自动启动引擎**）→ 显示 19 路棋盘 →
悬停预览合法落点 → 点击落子 → 把当前局面发给本地 KataGo → 显示 AI 推荐点（胜率、变化图）→ 可撤回/快进/分支
（含**快捷键 + 自动播放**）→ **复盘**（批量分析整盘 / 每手目损标注 / 胜率曲线）+ 终局点目；
可保存 `.kga.json` 项目文件，把分析缓存留到下次继续看。

> **学习系统闭环**（v5.0，改造方案见 [项目大纲.md](../项目大纲.md)）：问题手按学习优先级排序（每盘聚焦 5 个学习节点）；训练时棋盘自由落子主动复盘，榜外选点强制分析后按实际目损判定；九类技术错误分类必存证据；错题本记录完整作答历史与五档掌握状态；Human SL 识别当前棋力最值得改的错误（可选）；LLM 教练输出经程序校验、无网络完整可用。核心数据结构为 LearningEvent（learning_event.py），语言模型只能看到 EvidencePacket（evidence_packet.py）。

## 运行

```powershell
cd D:\katago\analyzer
python app.py
```

打开后：**自动启动 KataGo**（OpenCL 首次运行会做 GPU 调优，可能几十秒到数分钟；之后加载会明显更快，状态栏变“就绪”后自动分析）→ 在棋盘上点击落子 → 自动显示推荐点。

- **落子**：点击棋盘交叉点（黑白自动交替）
- **撤回 / 快进**：棋盘下方常驻的首尾/前后/播放导航，或 ←/→ 方向键
- **提示 / 悔棋**：同样常驻棋盘下方；`F1` 在棋盘标出 AI 首选，`Ctrl+Z` 悔棋。训练悔棋会同时撤销用户上一手和 AI 应手；点目悔棋会先退出点目。
- **快捷键**：`Home`/`End` 跳首尾 · `Space` 自动播放/暂停 · `PgUp`/`PgDn` 翻 10 手
- **产品快捷键**：`Ctrl+O` 导入 SGF · `Ctrl+S` 保存项目 · `Ctrl+L` 棋谱库 · `Ctrl+R` 刷新当前分析
- **▶ 播放**：点按钮或 Space 自动播放主线，再按暂停；到末尾自停；任何手动操作自停
- **分支**：撤回到某处后另走一手，即产生新分支（首个子节点为主线）
- **重新分析**：点【分析当前局面】强制重新请求当前局面分析
- **分析整盘**：点【分析整盘（批量）】后台分析主线全部节点（复盘必备，完成后导航零等待）
- **问题手深度对比**：整盘分析后自动深算最严重的 3 手；在问题棋模块切换【对比结论 / 实战变化 / AI变化】，棋盘显示最长 14 手编号主变。
- **三段式讲解**：问题手详情显示问题根因、AI 手目的、实战后果和证据来源；未完成双分支时明确标注为基础分析与棋形推断。
- **胜率曲线**：点【胜率曲线】弹出目差折线，点击跳转到那一手
- **导入文件**：点【导入 SGF】打开单盘；点【批量导入】多选 SGF 并排队；点【粘贴 SGF】直接粘贴完整文本；点【分析队列】暂停、继续或重试失败任务。
- **清空**：回到空盘

> 引擎未配置/启动失败时自动启动会安静跳过（状态栏提示），不影响手动【启动 KataGo】按钮。

## 界面分区（研究工作台）

- 顶部只保留【导入棋谱】【棋谱库】【保存】【明暗主题】四个全局入口。
- 顶栏使用单一绿色品牌色和“棋”标识；【导入棋谱】是唯一主操作，棋谱库、保存与主题主动退后。
- 顶栏常驻显示棋谱名、黑白双方、规则、贴目、当前/总手数和原始结果，并提供保存入口。
- 中部是可拖动分栏：左侧棋盘为视觉主体，右侧保持稳定可读宽度。
- 棋盘下方常驻首尾、前后、播放、进度、提示和悔棋；复盘时不必切换标签页。
- 空棋局提示“点击棋盘或导入 SGF”，回到已有棋谱根节点时改为“播放/下一步浏览”。
- 空棋盘提示采用与木色棋盘融合的阴影卡片和左侧强调条，不再呈现为系统弹窗。
- 右上“当前形势”同时显示行棋方、手数、黑白胜率、目差和领地。
- AI 推荐区没有结果时显示当前系统状态；分析完成后只展开实际有效候选，不再常驻灰色占位按钮。
- 右侧按真实研究路径分为【研究】【复盘】【棋谱】【导航】；复盘内部再分【总结】【问题手】，避免纵向堆叠和内容裁切。
- 棋谱库将“打开/训练”作为主操作，训练方与历史、错题、画像作为第二层工具。
- 曲线、棋局树、棋谱库、错题本、个人画像和设置等窗口跟随主窗口居中打开；设置窗口只保留一个实例。
- 底部状态按成功、进行中、警告、错误使用不同语义色；窗口尺寸、分栏和最近标签页在关闭时保存。
- 恢复窗口时会为标题栏和任务栏预留空间，旧机器保存的大窗口不会在较小屏幕上截掉底部导航。

按钮层级只有三档：绿色填充表示当前页面主操作，中性描边表示普通操作，浅底按钮表示低频工具。

## 复盘项目文件（分析缓存持久化）

SGF 适合交换棋谱；项目文件适合继续复盘。点【保存项目】会生成 `.kga.json`，保存整棵棋局树、变化图、每个节点的 KataGo `analysis` 缓存、当前停留节点、评论、点目结果、导入 SGF 的原 `RE[]`、规则与贴目。

下次点【打开项目】即可恢复这些内容，已经分析过的节点不会重新等待 KataGo。继续落子或分析后，可以再次保存项目。

## 本地棋谱库

点【导入 SGF】后，分析器会自动把原 SGF 和一份项目快照保存到 `analyzer/game_library/`：

- `game_library/inbox/` 是自动采集收件箱：把 `.sgf` 文件放进去，程序启动或打开【棋谱库】时会自动扫描、去重并入库
- `game_library/sgf/` 保存原始 SGF
- `game_library/projects/` 保存 `.kga.json` 项目快照
- `game_library/index.json` 保存棋谱索引
- `game_library/mistake_book.json` 保存跨棋局错题与复习进度

点【棋谱库】打开复盘历史列表：

- 点【打开收件箱】可直接打开自动采集目录；点【扫描收件箱】会立即重新扫描。
- 搜索框可按棋谱名、规则、来源路径过滤。
- 列表显示手数、已分析节点数、规则、贴目、最近打开/更新时间。
- 双击或点【打开选中棋谱】从项目快照继续复盘。
- 分析完成后会自动生成「最差阶段训练题」，棋谱库列表显示训练题摘要、我方和最近训练评分；可点【我执黑】/【我执白】/【双方】改变训练统计口径，点【开始阶段训练】可从该阶段前一手重新下。
- 设置画像身份并完成整盘分析后，高价值问题手会自动进入【错题本】；可只看今日到期、延期、标记掌握或直接开始隐藏答案测验。
- 点【删除记录】会移除库内 SGF 和项目快照，不会删除你导入时的原始来源文件。
- 分析结果回流后会更新当前库内项目，减少下次重复分析。

## 候选点说明

界面右侧按 KataGo 的 `order` 列出 1～5 个候选（默认五个，A 为首选）：

```
A  Q16  黑53.2%  目差 +1.8
     Q16→D4→Q3→R16→C4
```

- 胜率显示为当前行棋方视角；目差显示明确的黑/白领先方；同时展示该候选 visits
- 棋盘同步显示前三个候选圆点及当前方胜率，右侧列表显示设置数量的 A～E 候选
- 单击列表会同时高亮棋盘落点并查看该选 PV；双击列表直接落子
- 候选卡会标出"AI 最优 / 稳健易懂 / 易执行候选"。后两者只是基于候选目损、PV 长度、引擎 prior 与当前单局表现档的可解释筛选；`prior` 不等于人类落子概率。KataGo Human SL 模型（放入 `katago-runtime/models/` 自动启用）用于学习排序的"本人档 vs 更高档"选点概率对比，未放模型时优雅回退。

## 多来源导入与分析队列

- 【批量导入】支持一次选择多个本地 `.sgf`，坏文件单独报错，不阻断其他棋谱。
- 【粘贴 SGF】只解析用户粘贴的完整 SGF 文本，不访问网络。
- 棋谱按内容 SHA1 去重；重复导入不会覆盖既有分析项目。
- `game_library/analysis_queue.json` 保存队列状态；运行中断后会恢复为等待任务。
- 队列逐盘、逐节点分析；每 10 个节点周期性保存项目，暂停/停止/退出时立即保存；可继续、重试失败项，单盘或请求发送失败后自动处理下一盘。
- 本轮没有猜测 PlayGo、涨棋网或星阵的私有接口，也没有实现 URL 抓取和图片识棋。公开链接导入需后续按平台提供的稳定公开格式增加白名单解析器。

## 可配置主变（最佳后续走法）

点【主变 N 步】显示 AI 首选主变；N 可在设置中设为 1～30，默认 12：

- 棋盘按设置长度绘制带圈数字（黑步黑底白字、白步白底黑字，按当前轮次交替）
- 状态栏列出完整序列：`主变（第1选 Q16）：1.Q16  2.D4  3.Q3  …`
- **主变模式下点右侧推荐按钮可切换**查看任一已显示候选的主变
- 再点按钮退出；不足 N 步取实际，pass 跳过，点目模式下不显示

> 想比较不同计算宽度，可在【引擎/模型…】同时调整推荐点数量和主变显示长度。

## 形势判断（地盘图 + 目差 + 领地统计）

点【热力图】切到「地盘」即显示 **KataGo ownership 形势判断**：

- 每个空交叉点按归属显示清晰领地标记——**黑点=黑属地、白点=白属地**，点径按 |ownership| 分三档（铁地盘最大、边界争议较小），避免整格热力图模糊遮挡
- 胜率条下方有**大字形势判断**：`形势：黑 +3.5 目` / `形势：白 +7.2 目` / `形势：均势`（黑视角 scoreLead）
- 再下一行**领地统计**：`领地：黑 98 · 白 87`（按 ownership 统计黑/白各控制多少点，|v|>0.05 计入）——和精算目差互补，直观看地盘规模

> 中盘想知道谁领先：开「地盘」热力图 + 看大字目差 / 领地统计即可，不必等到终局点目。

## 单局表现估计

形势卡片底部给黑、白分别估计本盘表现。它不再直接使用全盘平均目损：

```
单局表现估计（非官方段位）
黑 业余6段表现（5段-7段+）｜稳健 0.31 · 有效 35/65
白 业余5段表现（4段-6段）｜稳健 0.58 · 有效 36/64
```

- **有效局面**：只统计落子前该方胜率处于 2%-98% 的手，胜负已定后的目差波动不用于棋力估计。
- **稳健目损**：每手最多计 3 目，避免一次战术崩盘支配整盘结论。
- **最低样本**：少于 8 手只显示“样本不足”；同时显示有效/全部手数、估计区间和可信度。
- **交叉校准**：库内两盘 `cter` 对野狐精灵官方 5 段的 129/247 手棋，白方均回算为 5 段表现；目标盘黑方为 6 段表现。

这是单盘竞技表现，不是账号段位或长期棋力认证。阶段摘要改用“优秀/稳定/有波动/问题较多”，不再把双方混合目损伪装成段位。

## 棋局进度条（拖动跳转）

棋盘右侧、播放按钮下方有一条**可拖动进度条**：

- **拖动滑块 / 点击轨道** → 跳转到主线第 N 手（比一步步 ←/→ 快得多）
- 旁边显示 `N / M`（当前手 / 主线总手）
- 落子、撤回/快进、Home/End、PgUp/PgDn、自动播放后进度条**自动同步**
- 点目模式下进度条跳转被拦截（先退出点目）

## 终局点目（中国规则 / 面积数法）

终局阶段点【点目（终局数棋）】进入点目模式：

- **地盘图**：黑地（深色小点）/ 白地（浅色小点）/ 中立（黄点）按面积法 flood fill 实时计算
- **标记死子**：点目模式下点击棋子标记/取消死子（红色 X）；被标记棋子计分时视作移除
- **AI 死子建议**：若当前局面已有 KataGo ownership，进入时弹窗询问是否采用建议；也可点【AI 死子建议】手动采纳（黑子 ownership 强偏白 / 白子强偏黑 即判死）
- **结果面板**：右侧实时显示黑/白活子、地、贴目、合计、胜负、死子清单
- **双 Pass 提示**：连续两手 pass 时弹窗询问是否进入点目（不强制）
- **确认结果**：点【确认结果】锁定点目，写回 `tree.score_result`；之后【导出 SGF】写入 `RE[]`（如 `B+3.5` / `W+7.5` / `0`）并在根 `C[]` 追加完整点目摘要（不覆盖原注释）。未确认但导入的原 `RE[]` 会被保留

面积数法：

```
黑方面积 = 黑活子数 + 黑属地空点数
白方面积 = 白活子数 + 白属地空点数 + 贴目
margin  = 黑方面积 − 白方面积（正=黑胜，负=白胜）
```

第一版只实现中国规则；暂不支持日本规则精确点目、复杂双活、提子计税、非 19 路。详见 [score_estimator.py](score_estimator.py)。

## 复盘三件套（批量分析 / 每手目损 / 胜率曲线）

把分析器从「逐手看 AI 推荐」升级为「**复盘教练**」——直接回答「这盘哪几手下错了、错多严重、形势在哪手逆转」。

- **【分析整盘】**：把主线全部节点一次性发给 KataGo（后台并发，走 `analysis_guard` 防污染）；进度显示 `已分析 X/N`，完成后沿主线导航**零等待**（命中缓存）。
- **问题棋分析**：仍计算逐手目损作为底层数据，但 UI 不再罗列所有手。只显示胜负仍有悬念时造成明显目损或胜率下降的问题棋，列出手数、实战、目损、胜率损失和 AI 建议，双击直接跳转；胜负已定后的巨大目差不会混入。
- **恶手意图对比**：仅对目损 ≥ 6 的恶手生成。单击红色恶手后，下方滚动面板对比“实战选点可能意图 / AI 推荐选点意图 / 核心差异”，依据落点区域、邻接敌我棋、连接、接触、提子、气数和 AI 主变推断。
- **三阶段表现分析**：自动按主线手数划分 **布局 / 中盘 / 关子**，分别统计平均目损、质量评价、好/普通/疑问/恶、代表好手和重点问题手。
- **对局文字分析**：复盘页自动说明全局结果、各阶段形势、最大目损、关键胜率转折和有胜负意义的复盘重点；胜负已定阶段会明确标注。
- **【胜率曲线】**：弹出窗口画黑视角 `scoreLead` 折线（上=黑好/下=白好），失误点叠红，当前手竖线；**点击曲线**跳到那一手。批量分析回流时实时刷新。
- **【导出报告】**：生成 Markdown 复盘报告，包含结论摘要、单局表现估计、对局文字分析、三阶段表现、有效问题棋和恶手意图对比；不再附冗长的逐手评价表。

视角：`analysis.cfg` 的 `reportAnalysisWinratesAs = BLACK`，故 `scoreLead/winrate` 恒为黑视角；`loss` 取**走子方**视角（黑走 `S_best − S_actual`，白走 `S_actual − S_best`），越大越差。详见 [review.py](review.py)。

## 阶段训练模式

导入 SGF 入库后，分析器会尝试自动启动 KataGo 并分析整盘；主线分析完成后，棋局库会自动生成一条「最差阶段训练题」。棋局库打开且引擎就绪时，会在后台为未生成训练题的离线棋局补主线分析并写回 `trainingTask`，不切走当前棋盘。如果训练题还没生成，直接点【开始阶段训练】即可，系统会自动启动/等待引擎、分析整盘、生成训练题，完成后进入训练，不需要用户先手动点【分析整盘】。它不是抓单手最大失误，而是用约 36 手滑动窗口寻找累计表现最差的阶段，综合累计目损、胜率损失、疑问/恶手数量和连续问题手。训练题支持按【我执黑】/【我执白】/【双方】过滤，避免把对手下差的一段误当成你的训练题。

- 训练题保存在 `game_library/index.json`；预生成应手独立保存在 `game_library/training_cache/<棋局ID>.json`，不会把假想变化污染复盘棋树。
- 生成训练题后，后台会沿训练阶段最多预演 20 个回合；每个用户回合预计算前三个候选、AI 应手及应手后的局面。棋局库「快速训练准备」列显示回合数和缓存局面数。
- 这不是重新训练 KataGo 神经网络权重，而是为该棋局建立可持久化的应手缓存树。模型、规则、贴目、训练 visits 或我方设置变化时，旧缓存自动失效并重建。
- 训练对弈使用独立的「训练速度」visits（默认快速 80），比复盘 `maxVisits` 更轻，进入训练后能更快和 AI 来回下。
- 进入训练后优先从磁盘缓存读取，不要求 KataGo 处于开启状态；若走入未覆盖分支，系统才静默启动 KataGo 补算，并把新局面继续写回缓存。训练中不主动纠错、不打断思考，评价统一留到结束后。
- 点【开始阶段训练】后，棋盘回到该阶段开始前一手；如果还没轮到你的执棋方，AI 会先补到你的回合。
- 训练长度取该问题阶段长度，上限约 40 手；结束后自动补齐分析并生成训练评价。
- 训练时会隐藏候选点，避免直接看到答案；需要帮助时点【提示】，也可【结束训练】、【重来】、查看【原实战】问题摘要。
- 训练评价只统计你的执棋手，对比原问题阶段同方平均目损，给出 A/B/C/D、改善幅度、好/普通/疑问/恶统计、训练中的好手/问题手和下一步建议。
- 训练变化会作为棋树分支随项目快照保存，训练评价会追加到棋局库索引；点【训练历史】可查看最近记录。

## 精细评价、训练分析与个人画像

- 每个已分析走子统一生成“AI 参考评价”：最佳 / 好手 / 一般 / 不佳 / 恶手，并显示目损、胜率损失、完整 AI 排名、置信度、原因和启发式问题标签。
- 复盘工具提供【复盘范围：我方/双方】切换；我方范围会同步过滤问题榜、阶段统计、文字复盘、曲线问题点、深度比较队列和导出报告，避免把对手失误当作自己的训练重点。
- 阶段概览显示当前范围的分析覆盖率、有效评价手数和关键问题数量；进度条明确标出待补手数，并可在复盘页直接【补全整盘】。
- 训练结束后保存结构化报告，区分同一局面的改善/重复/新错误，以及分支变化后的问题模式重复；提示和重试会进入评分，报告给出建议复习天数。
- 整局分析完成后，项目保存轻量 `reviewSummaryV2`，棋局库保存 `profileSummary`；不重复保存 ownership、policy 或完整候选分析。
- 在【棋谱库】中为棋局设置独立的画像身份（我执黑 / 我执白 / 双方），再点【个人画像】查看最近 N 盘的加权趋势、黑白表现、阶段弱点、常见问题和优先训练局面。
- 单局摘要只统计画像身份对应的本人走子，不再把对手的目损、阶段数据或问题标签混入个人结论。
- 个人画像增加逐盘平均目损曲线和“最近一盘 vs 个人历史基线”；基线按有效手数加权，并明确显示历史盘数与置信度。
- 个人画像首页使用结构化指标卡展示纳入棋局、有效手数、平均目损、总体趋势和今日到期错题；优先训练改为表格，不再要求从长文本中找重点。
- 弱点近期变化按每百手问题频率比较最近窗口与此前窗口；前后各少于 2 盘同口径棋局时只显示“样本不足”，不会把单盘波动包装成进步。
- 个人画像可直接【开始今日复习】或【打开错题本】，把长期诊断接回自己的实战错题。
- 模型、规则、贴目或评价版本不同的棋局不会被静默混入趋势；同一配置下 KataGo 实际 visits 的小幅自然波动允许比较，跨强度档位仍隔离。
- 点【导出个人分析报告】可保存 Markdown，包含核心指标、阶段/黑白表现、逐盘趋势、弱点建议和当前复习队列。
- “优先训练”会结合跨局问题出现次数、活跃/到期错题数和错题平均目损排序，并逐项显示证据，不生成不透明的综合战力分。

## 我的棋风与成长路线

- 从【个人画像】进入【棋风与成长路线】，基于已有 `reviewSummaryV2.moveQuality` 生成 8 个统计维度：实地确认、外势发展、主动求战、稳健选择、脱先倾向、优势局继续施压、劣势局复杂化、官子收束。
- 每个维度显示本人样本数、每百手频率、平均目损、不佳/恶手率、最近趋势、成本结论和置信度；少于 3 盘或少于 5 个相关样本不输出强结论。
- 成本分类区分“可保留、继续观察、需要修正、样本不足”，成长路线最多给一个主线目标，避免同时塞入一串训练任务。
- 可导出《个人棋风与成长路线报告》，包含数据范围、维度表、可保留风格、高成本习惯、成长主线、代表问题手和固定边界说明。
- 【生成复核队列】只从已进入成长路线的关键结论选取代表手，每个结论默认最多 3 手；【开始复核】会使用 800 visits 分别复核落子前后局面。
- 复核若显示代表样本不稳定，相关结论会从主修正项降为继续观察。复核队列和结果原子保存到 `game_library/deep_verification.json`。
- 当前真实数据仅 2 盘，因此棋风窗口会显示 8 个维度，但所有强结论均按低置信边界降级；不会为了产出报告强行贴“战斗派/实地派”等固定标签。

## 错题本与间隔复习

- 完整分析写入 `profileSummary` 后，最值得复盘的问题手自动同步到错题本；画像身份为黑/白时只收录自己的棋。
- 【开始复习】会回到问题手之前并隐藏候选答案。命中 AI 首选记为 `good`，命中前三选记为 `hard`，其他落点记为 `again` 并回到题面重试。
- 答错默认次日再练；首选命中采用更长间隔。可手动【明天再练】或【标记已掌握】。
- 棋谱重新分析只更新题面，不清空复习进度；删除棋谱会同时清理对应错题。
- 问题棋面板提供【上一问题 / 下一问题】和“问题 x/y”定位；跳转或分析回流后保持当前选择，不会反复跳回第一条。
- 右侧工作区加宽到完整容纳问题表，恶手/不佳使用克制的浅色语义底；单局表现与画像摘要分行显示，不再重叠。

## 切换引擎/模型（配置窗口）

点右侧【引擎/模型…】打开配置窗口：

- 引擎下拉框会自动列出 `katago-runtime` 中的 CPU/GPU 引擎（默认优先 GPU/OpenCL，CPU 版保底）。
- 模型下拉框会自动列出 `models\*.bin.gz`（默认轻量 b18，另有更强但更慢的 b28）。
- 可设置规则、贴目、复盘 `maxVisits`、推荐点数量、主变长度、训练速度、棋局库后台 visits，并点【检测配置】做启动前检查。
- 复盘范围默认跟随画像身份只看我方；需要研究整盘双方决策时可在复盘工具中切换，选择会持久化。
- 复盘预设：`快 80` 更快但较浅，`标准 200` 平衡，`深入 800` 更稳但更慢。
- 训练速度：`快速 80` / `均衡 140` / `精细 240`，只影响训练对弈、提示和训练评价补分析。
- 点【应用】后写入 `user_settings.json`；引擎或模型变更时，若当前引擎正在运行会自动重启。

调强：在设置窗口把复盘 `maxVisits` 调大（如 800）分析更深但更慢；训练想更顺滑则保持「快速」。OpenCL 启动失败时可切回 `katago-eigenavx2.exe`。
