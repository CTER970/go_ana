        KataGo 围棋分析器 · 快速开始（新手）
════════════════════════════════════════════════


【第一次使用，只需两步】

  ① 双击  create-shortcut.bat
     → 桌面会出现一个「GoAnalyzer」图标

  ② 以后双击桌面那个「GoAnalyzer」图标
     → 直接打开围棋分析器，就能用了


【不想建快捷方式？直接打开】

  双击  run.bat  也能打开。


【打开后怎么用】

  · 自动启动引擎，等几秒状态栏变「就绪」即可落子
  · 点棋盘交叉点落子（黑白自动交替）
  · 左/右 方向键      撤回 / 快进 一手
  · Home / End        跳到第一手 / 最后一手
  · 空格              自动播放 / 暂停
  · PgUp / PgDn       一次翻 10 手
  · 右侧「AI 推荐点」双击可直接落子
  · 点「分析整盘」一键分析整局；点「胜率曲线」看形势走向
  · 终局点「点目」标记死子算胜负


【打不开？提示「未找到 Python」】

  说明电脑还没装 Python：
    1. 打开 https://www.python.org/downloads/
    2. 下载并安装 Python 3
    3. 安装时务必勾选  Add Python to PATH   （重要！）
    4. 装完后重新双击 run.bat 或桌面图标


【更多功能 / 遇到问题】

  详见  analyzer\README.md  和  项目说明.md
